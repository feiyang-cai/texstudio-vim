# texstudio-vim

An experimental fork of [TeXstudio](https://github.com/texstudio-org/texstudio) with native Vim-style editing. Vim mode is enabled by default for fresh configurations.

See [VIM_MODE.md](VIM_MODE.md) for supported commands and limitations.

## Downloads

Get Linux, Windows and macOS builds from [GitHub Releases](https://github.com/feiyang-cai/texstudio-vim/releases).

Versions use `texstudio-vim-<upstream-version>-rN`, where `rN` tracks the fork revision independently of upstream.

## Important warning

This fork's changes are largely generated by AI coding agents, with human guidance and testing. Not every code path has been manually reviewed. Vim support remains experimental and incomplete; use it carefully and keep backups of important work.

## Issues and feedback

For bugs, suggestions or feedback, please [open an issue](https://github.com/feiyang-cai/texstudio-vim/issues). For bugs, include your version, operating system and steps to reproduce.
